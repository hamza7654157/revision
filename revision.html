1. Introduction

Origine & définition

Le terme vient d' Al-Khawarizmi. Un algorithme est une suite d'instructions permettant de résoudre un problème étape par étape. Exemple : recette de cuisine, mode d'emploi.

2. Étapes de conception

  • Analyse : comprendre le problème.
  • Conception : définir les étapes.
  • Implantation : traduire en code.
  • Test : vérifier le fonctionnement.

3. Caractéristiques

  • Clair et précis
  • Ordre d'exécution défini
  • Résout le problème
  • Indépendant du langage

4. Algorithmique & programmation

Un programme est la traduction d'un algorithme dans un langage. Le processeur exécute ces instructions. La programmation sert à traiter des données et obtenir des résultats.

5. Langages de programmation

Langage machine — binaire
Assembleur — proche du processeur
Interprétés — HTML, Maple, Prolog
Compilés — C, C++, Cobol
Intermédiaires — Java, Python

Interprétés : souples mais lents. Compilés : rapides mais nécessitent recompilation.

6. Démarche

  1. Analyse
  2. Écriture de l'algorithme
  3. Traduction en programme

  5. Tests et résultats

7. Pseudo-langage

Structure lisible : Algorithme NomAlgorithme — déclarations — Début ... Fin. Utilise des commentaires /* ... */.

8. Variables & types

  • Entier — nombres sans virgule
  • Réel — nombres à virgule
  • Caractère — un symbole
  • Chaîne — texte
  • Logique — Vrai / Faux

9. Affectation & opérateurs

Affectation : X ← 3. Opérateurs : +, -, *, /, ^. Concaténation : &.

10. Entrée / Sortie

Lire() pour saisir, Écrire() pour afficher.

11. Structures conditionnelles

Exemples : Si ... Alors ... Sinon ... FinSi et Selon ... Faire pour choix multiples.

12. Structures répétitives (boucles)

  • TantQue condition Faire — boucle testée avant l'action.
  • Répéter ... Jusqu'à — boucle testée après l'action.
  • Pour i de 1 à N Faire — boucle avec compteur.
